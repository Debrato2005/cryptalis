FACTS (verified canonical documentation, 2026-10-06):
- Final architecture is DESIGNED. Status records 612 parser/structural/synthetic tests, zero verified production cells and no independent crypto audit. No protected ORM, live provider, transition executor or restore admission currently exists.
- Selected integration: attached SQLAlchemy session factory, ordinary logical attributes/equality queries, public hooks only. Sync/async reads collect private bounded rows, prepare keys, authenticate every projected field and predicate leaf, preserve pending assignments separately, then publish complete buffers. No scalar provider I/O, streaming, private ORM machinery, implicit lazy loads or plaintext fallback.
- Storage: same-row ciphertext and full 256-bit HMAC equality terms, visible immutable tenant/record/subject IDs, NULL companions. Original SQL constraints need mapping. Guarded engine rejects raw/bulk; roles/catalog/writer inventory exclude unsupported writers. Framing constraints do not authenticate. Host app/grants and authorized release/operator are trusted.
- Crypto: AES256-GCM-SIV, random 96-bit nonces, independent wrapped scope roots, HKDF-SHA256, hashed typed AAD binding descriptor/domain/tenant/subject/record/field/representation/generation/full header. Trusted exact-key registry, no key commitment promise. Durable reservations charge attempted encryptions; per root-generation 2^24 calls or 2^40 bytes. Bare codec2 text/bytes/integers/Decimal. Separate per-tenant-field search root; equality/IN/uniqueness only, declared leakage, no low-cardinality search.
- Authority: one pinned regional DynamoDB table with conditional current epochs/head/tombstones, same-region independently administered S3 ObjectLock exact-version intents, 100-year retention. Every protected transaction holds shared domain PostgreSQL fence. Lifecycle first denies new affected admissions then drains known publications/commits and takes exclusive fence. Unknown workers/ambiguous effects remain pending.
- Custody: dedicated AWS-generated single-region KMS domain KEK, workload credentials; memory-only roots <=300s, operations <=30s, fresh publication/commit admission. Async boto3 bounded executor with cancellation ownership. Authority outage denies even warm keys.
- Lifecycle: one maintenance engine PLAN/PREPARE/TRANSFORM/VERIFY/SWITCH/OBSERVE/FINALIZE, full terminal verification, no online backfill, one operation per domain. Same-row current rollback mirrors atomic; protection mirror plaintext default24h, absolute7d deadline blocks mirrored writes. Package removal needs package-free app proof plus standalone current-authority recovery reader. Restore requires new exact RDS resource incarnation and current authority. Unprovable permanent authority loss permanently denies old domain even if keys survive.
- Subject shred is managed denial, not cryptographic erasure; surviving backup wrappers/domain KEK and shared terms remain recoverable/linkable. Domain destruction is bounded by observed provider deletion and known copies. Same-context replay, omission, nullable substitution, host compromise and released plaintext remain explicit exclusions.
